# Island Lab: эксперимент нижнего слоя Windows

**Статус:** реализован обратимый пробный режим. На Windows ещё не проверен. Это **не** полноценное прикрепление виджета к Explorer / WorkerW.

## Зачем

Цель Island Lab — находиться **на рабочем столе**, а не висеть поверх браузеров, игр и других окон. На первом этапе мы проверяем штатный метод Tauri `WebviewWindow::set_always_on_bottom(true)`, не модифицируя окна Explorer. Этот метод может поместить островок **ниже поверхности значков рабочего стола** — тогда виджет станет невидимым. Поэтому режим нельзя включать по умолчанию и сохранять между запусками.

## Как проверить

1. Собери и запусти нативный Island Lab (см. [native/README.md](native/README.md)).
2. Раскрой капсулу и открой **Настройки → Размещение на рабочем столе**.
3. Нажми **«Проверить 20 секунд»**. Окно перейдёт в нижний слой, запустится независимый Rust-таймер возврата.
4. Открой обычное окно и вернись к рабочему столу. Проверь, виден ли Island **над обоями и значками**, или он полностью скрылся под ними.
5. Если островок остаётся видимым и кликабельным — нажми **«Оставить до перезапуска»** в пределах 20 секунд. Для отмены доступна кнопка **«Вернуть обычное окно»**.
6. Если окно исчезло или стало недоступным, ничего делать не нужно: **через 20 секунд нативный Rust-таймер возвращает обычный порядок окон**. Таймер работает даже если JavaScript не обновляет экран.
7. Перезапусти приложение: режим нижнего слоя должен быть **выключен**, даже если до этого нажимали «Оставить».

| Клики | Нет ли блокировки рабочего стола за пределами капсулы? |

## Защитные ограничения

- Не вызываем `SetParent`, не ищем `Progman`/`WorkerW`, не посылаем сообщения системной оболочке.
- Не скрываем Island из панели задач: так остаётся запасной способ управления.
- Все изменения порядка окон обратимы из интерфейса или независимым таймером.
- Режим не сохраняется на диск, не включается автоматически и не изменяет Snowy New Year.
- При неудачном создании таймера Rust немедленно пытается вернуть обычное окно.
- Обычный выход из приложения — **Настройки → Выйти** либо `Alt+F4`.

## Критерий решения

Если `always-on-bottom` делает Island недоступным/невидимым либо он минимизируется через `Win+D`, **не включать его в продакшене**. Следующий этап — отдельный Windows-адаптер с исследованием надёжного прикрепления к слою рабочего стола, обработки перезапуска Explorer, восстановления HWND и переходов между виртуальными рабочими столами. Любые операции с недокументированными окнами Explorer — только в отдельном эксперименте, с сохранением аварийного возврата.
