# Island Lab — план разработки

## Концепция

Island Lab — **самостоятельный Windows-виджет рабочего стола** в стиле Dynamic Island. В свернутом состоянии небольшая капсула: слева три кнопки управления плеером, справа погода, в центре пространство. В раскрытом состоянии — три колонки (музыка, три синхронные строки текста, погода) и отдельные вкладки Скриншоты / Snowy New Year / Блокнот / Настройки. Новости исключены.

Самая узнаваемая часть — **нижний край окна**, который при музыке превращается в направленные вниз аудиореактивные выступы. Это часть силуэта самого островка, а не полоска визуализатора внутри него. В паузе край выпрямляется.

## Архитектурные принципы

1. Островок — единый процесс, отдельные модули работают по событиям и не обязаны обновляться на каждом кадре.
2. Графика нижней границы получает только нормализованные уровни частот; она не должна зависеть от API конкретного плеера.
3. Пользовательское содержимое (заметки, файлы, скриншоты) по умолчанию остаётся локально.
4. Не заявлять нативные функции доступными, пока реально не реализованы и не протестированы.
5. Не использовать исходный `main` Snowy New Year в качестве хранилища экспериментальной функциональности.
