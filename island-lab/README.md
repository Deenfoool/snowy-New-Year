# Island Lab

**Отдельный проект Windows Dynamic Island, работающий в собственной ветке** `feature/island-lab` репозитория Snowy New Year.

Это самостоятельный модуль, а **не новый экран Snowy New Year**. Существующий Rust-движок снегопада не изменяется.

## Запуск веб-прототипа

Открой `island-lab/index.html` в Chrome/Edge. Прототип не требует сборки, npm, Node.js или установки библиотек. Стили и логика лежат рядом в `styles.css` и `app.js`. Чтобы проверить браузерный захват экрана, рекомендуется открыть страницу с localhost или HTTPS:

```bash
cd island-lab
python -m http.server 8080
```

Затем открой http://localhost:8080

Если скачиваешь весь репозиторий ZIP-файлом, выбери ветку `feature/island-lab`, распакуй архив и открой `island-lab/index.html`.

## Возможности прототипа

| Раздел | Реализовано в браузере |
|---|---|
| Свернутая капсула | Назад / воспроизведение-пауза / вперёд слева, свободная область по центру, погода справа |
| Раскрытая панель | Три колонки: проигрыватель, трёхстрочный барабан текста, компактная погода |
| Музыка | Оригинальный демо-синтезатор Web Audio, **очередь до 50 локальных аудиофайлов**, переключение назад/вперёд, автозапуск следующего, перемотка |
| Проигрыватель Windows | **Экспериментально, только нативная версия:** добровольное подключение к Windows Media Sessions, название/исполнитель, пауза/продолжение, следующий/предыдущий трек и позиция |
| Текст песни | Локальный `.lrc`, **поиск через LRCLIB по кнопке**, проверка названия/исполнителя/длительности, смещение текста ±10 с |
| Нижняя граница | Прозрачный Canvas *за пределами* прямого низа панели; частотный анализ Web Audio и выступающие вниз волны |
| Погода | Демо по умолчанию, онлайн-погода по **введённому вручную** городу через Open-Meteo |
| Скриншоты | Захват с разрешения браузера, вставка Ctrl+V, карандаш, маркер, стрелки, прямоугольник, овал, текст, ластик, **неразрушающая обрезка**, отмена/повтор с лимитом памяти, сохранение PNG. **Windows-хост** сохраняет PNG в `Изображения/Island Lab` и открывает эту папку через Проводник |
| Блокнот | Несколько заметок, автосохранение через `localStorage`, удаление |
| Snowy New Year | Веб-демонстрация снегопада и переключателей; исходное приложение не управляется |
| Настройки | Цвет, интенсивность волны, снижение анимации, демонстрационный снег, положение панели |

## Ограничения

**Это веб-прототип, не исполняемый файл Windows.**

- Не может встроиться в системный слой рабочего стола Windows или получить настоящую форму окна. Canvas имитирует нижнюю волнистую границу.
- Не имеет Windows Media Sessions: воспроизводит только файлы, загруженные в страницу, либо встроенный демо-синтезатор. Настоящие треки из системных проигрывателей пока не отображаются.
  **Уточнение:** это ограничение только веб-страницы. В папке `native/` добавлен адаптер Windows Media Sessions, который ещё требуется проверить на настоящей Windows-сборке. Он не работает со всеми проигрывателями и включается отдельным переключателем.
- Веб-страница без нативного хоста анализирует **только звук, воспроизводимый самой страницей**. В экспериментальном Windows-хосте добавлен WASAPI-захват системного микса по отдельному переключателю. Он слышит **все звуки выбранного устройства вывода, включая уведомления Windows**, а не только активный музыкальный плеер. Захват включается вручную и выключается при сворачивании/скрытии страницы или отключении функции. Не записывает аудио на диск и не отправляет его в интернет. Точечный Application Loopback по процессу — следующий этап.
- Не может гарантированно перехватывать Print Screen. Если браузер получил нажатие, открывается редактор; скриншот Windows нужно вставить Ctrl+V. Для полного перехвата нужна отдельная Windows-интеграция с учётом стандартных сочетаний.
- Обычная **веб-страница** не может открывать произвольные папки Проводника, поэтому PNG скачивается через браузер. **Нативная Windows-версия** имеет отдельные команды сохранения в `Изображения/Island Lab` и открытия папки. При сбое записи сохраняется браузерная загрузка.
- `Open-Meteo` работает только с интернетом и при явном вводе города. Стартовая погода помечена **DEMO**, пока нет подтверждённого ответа.
- Онлайн-поиск текстов осуществляется **только по кнопке** через LRCLIB (название/исполнитель отправляются этому сервису). Наличие синхронизированного текста не гарантировано; нет результатов — остаётся локальный LRC или демонстрация. Соблюдать условия использования и права на тексты.
- У истории редактора установлен лимит памяти 64 МиБ, поэтому на больших скриншотах число доступных шагов отмены может быть небольшим. Изображения с большей стороной свыше 4096 px уменьшаются с сохранением пропорций.
- Заметки и параметры сохраняются только в том браузере, где открыта страница. Снимки редактируются локально без загрузки на сервер.

### Проверка кода

При установленном Node.js:

```bash
node --test island-lab/tests/smoke.mjs
```

Проверяется синтаксис JavaScript, уникальность DOM ID, ссылки на ресурсы, разбор LRC, подбор синхронных текстов и геометрия обрезки. Тест не заменяет проверку в Windows и ручной UX-проход.

Основная ветка `main` намеренно не изменяется.

## Проверка нативной версии на Windows

Для первого запуска из PowerShell на Windows 10/11:

```powershell
git checkout feature/island-lab
powershell -NoProfile -ExecutionPolicy Bypass -File .\island-lab\scripts\test-windows.ps1
```

Скрипт запускает `npm install`, затем тесты Node.js и компиляцию Tauri в неподписанный `.exe`. Перед этим должны быть установлены **Node.js, Rust (MSVC) и Visual Studio Build Tools с компонентом «Desktop development with C++»**. <https://v2.tauri.app/start/prerequisites/>

Бинарный файл после успешной сборки: `island-lab/native/src-tauri/target/release/island-lab-native.exe`.

В приложении открой **Настройки → Проверка приложения → Проверить**. Скопируй отчёт. Он не включает заметки, имена аудиофайлов, содержимое скриншотов или город.

**Чек-лист ручной проверки:** 1) свернуть/развернуть капсулу; 2) перетащить за пустую область и развернуть повторно — положение не должно прыгать; 3) переключить несколько локальных треков; 4) проверить LRCLIB и LRC-смещение; 5) импорт/обрезка/undo/redo/PNG; 6) автосохранение блокнота; 7) вкладка «Настройки → Выйти из Island Lab»; 8) CPU/GPU в покое.

GitHub Actions задание `island-lab-windows.yml` предназначено для сборки на `windows-latest` и загрузки неподписанного `.exe`, **но наличие workflow не подтверждает, что оно реально запустилось**.

> Важно: текущая нативная оболочка — обычное прозрачное Windows-окно, **не закреплённое за рабочим столом Explorer**. Режим desktop-only будет реализован только после проверки базовой оболочки на Windows, чтобы не создавать невидимое окно или перехват обычных кликов.

### Проверка WASAPI на компьютере

В нативном приложении включи **«Плеер Windows»**, запусти музыку в совместимом приложении и отдельно включи **«Волны из звука Windows»**. Нижний край Island должен реагировать на музыку и **выравниваться в тишине**. В расширенных настройках найдёшь состояние `WASAPI Loopback` в диагностическом отчёте.

Проверь отключение переключателя и закрытие окна — поток захвата не должен оставаться активным. Если захват недоступен, он должен показывать ошибку и оставаться выключенным; локальное воспроизведение музыки при этом продолжает работать.

Демонстрационный браузерный режим **никогда не запрашивает доступ к общему звуку компьютера**.

Последовательность настройки: [native/README.md](native/README.md). Документация Microsoft: <https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording>.

## Пробный режим рабочего стола

В нативную Windows-оболочку добавлена **отключаемая 20-секундная проба размещения под обычными окнами** (Настройки → Размещение на рабочем столе). При исчезновении островка нативный таймер возвращает обычное положение. Режим никогда не включается автоматически и не сохраняется после перезапуска. Это пока **не прикрепление к Explorer/WorkerW**. Подробности: [DESKTOP_LAYER_TEST.md](DESKTOP_LAYER_TEST.md).

## Нативные скриншоты

В Windows-версии редактор содержит кнопку **«Открыть папку»**, а «Сохранить PNG» создаёт новый файл в системной папке `Изображения/Island Lab`. Пути берутся из Windows Known Folders, а имена снимков генерирует Rust; существующие файлы не заменяются.

Проверь на ПК: загрузка картинки → карандаш/стрелка → обрезка → сохранить PNG → открыть папку → убедиться, что изображение экспортировано с правками. Не все программы разрешают браузерный захват экрана, и **глобальный перехват Print Screen пока не готов**.

При отключении WASAPI во время начального подключения теперь ждём завершения стартового запроса, а затем гарантированно отправляем остановку. На Rust-стороне запуск/остановка защищены общим мьютексом, поэтому источник звука не должен оставаться активным после отключения.

## Плавные анимации Island Motion

В Island Lab добавлена единая система переходов: **пружинное раскрытие и сворачивание**, маска, скрывающая содержимое за краем меняющей форму капсулы, скользящий индикатор вкладок, трёхстрочный барабан текста песни, плавная смена метаданных, волна с инерцией и снегопад с обновлением по частоте экрана.

В настройках можно переключать **«Плавный пружинный»**, «Быстрый отзывчивый» и «Спокойный мягкий», отключать анимации и запускать **8-секундный замер FPS/P95**. По результатам замера можно копировать технический отчёт.

Подробная спецификация и сценарий для проверки: [MOTION.md](MOTION.md). Нативная Windows-версия использует тот же интерфейс, но фактические FPS и плавность композитора WebView2 необходимо проверить на настоящем компьютере.

## Быстрый запуск для проверки анимаций без Rust

Достаточно Node.js 20+ и актуальной рабочей ветки:

```powershell
git fetch origin
git switch feature/island-lab
node island-lab/scripts/preview.mjs
```

Открой **http://127.0.0.1:4173/** в Edge/Chrome. Для остановки нажми `Ctrl+C`. Сервер слушает только `127.0.0.1`, не требует npm-пакетов и отдаёт только файлы веб-интерфейса — исходники Rust и папка `.git` недоступны. Скрипт также запускается из `island-lab/native` командой `npm run preview`.

Веб-просмотр позволяет оценить раскрытие капсулы, плавность вкладок, барабан LRC, снег, встроенную музыку, анимацию обложки и 8-секундный тест FPS. **Плеер Windows, WASAPI, нативное сохранение PNG и размещение на рабочем столе доступны только в нативной Windows-версии**.

### Доступность и FPS

Для управления вкладками с клавиатуры используй **← / →**, **Home / End**. **Esc** сворачивает островок и возвращает фокус к кнопке раскрытия. Включённый в Windows режим снижения анимаций также останавливает декоративные циклы JS.

Волна обновляется в такт доступным кадрам экрана, а градиент и геометрия повторно используются в стабильных кадрах. Реальная плавность на 120/144 Гц остаётся **задачей проверки на ПК** — исходники и математические тесты не гарантируют фактические FPS.

### Дополнительная полировка перед проверкой на ПК

Устранены рывки из-за частого переразмера аудио-Canvas, добавлено запоминание прокрутки по вкладкам и устойчивое перетаскивание на сенсорных экранах. Запуск и остановка захвата WASAPI не должны блокировать главный поток интерфейса. Следующий этап проверки — воспроизвести эти сценарии в настоящем WebView2.
