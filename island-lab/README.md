# Island Lab

**Отдельный проект Windows Dynamic Island, работающий в собственной ветке** `feature/island-lab` репозитория Snowy New Year.

Это самостоятельный модуль, а **не новый экран Snowy New Year**. Существующий Rust-движок снегопада не изменяется.

## Запуск веб-прототипа

Открой `island-lab/index.html` в Chrome/Edge. Прототип не требует сборки, npm, Node.js или установки библиотек. Стили и логика лежат рядом в `styles.css` и `app.js`. Чтобы проверить браузерный захват экрана, рекомендуется открыть страницу с localhost или HTTPS:

```bash
cd island-lab
python -m http.server 8080
```

Затем открой http://localhost:8080

Если скачиваешь весь репозиторий ZIP-файлом, выбери ветку `feature/island-lab`, распакуй архив и открой `island-lab/index.html`.

## Возможности прототипа

| Раздел | Реализовано в браузере |
|---|---|
| Свернутая капсула | Назад / воспроизведение-пауза / вперёд слева, свободная область по центру, погода справа |
| Раскрытая панель | Три колонки: проигрыватель, трёхстрочный барабан текста, компактная погода |
| Музыка | Оригинальный демо-синтезатор Web Audio, загрузка пользовательских аудиофайлов, перемотка |
| Текст песни | Локальный `.lrc`, **поиск через LRCLIB по кнопке**, проверка названия/исполнителя/длительности, смещение текста ±10 с |
| Нижняя граница | Прозрачный Canvas *за пределами* прямого низа панели; частотный анализ Web Audio и выступающие вниз волны |
| Погода | Демо по умолчанию, онлайн-погода по **введённому вручную** городу через Open-Meteo |
| Скриншоты | Захват с разрешения браузера, вставка Ctrl+V, карандаш, маркер, стрелки, прямоугольник, овал, текст, ластик, **неразрушающая обрезка**, отмена/повтор с лимитом памяти, сохранение PNG |
| Блокнот | Несколько заметок, автосохранение через `localStorage`, удаление |
| Snowy New Year | Веб-демонстрация снегопада и переключателей; исходное приложение не управляется |
| Настройки | Цвет, интенсивность волны, снижение анимации, демонстрационный снег, положение панели |

## Ограничения

**Это веб-прототип, не исполняемый файл Windows.**

- Не может встроиться в системный слой рабочего стола Windows или получить настоящую форму окна. Canvas имитирует нижнюю волнистую границу.
- Не имеет Windows Media Sessions: воспроизводит только файлы, загруженные в страницу, либо встроенный демо-синтезатор. Настоящие треки из системных проигрывателей пока не отображаются.
- Не захватывает все звуки компьютера; волну создаёт из **музыки самого прототипа**. Для отдельного музыкального приложения в нативной версии понадобится WASAPI Application Loopback.
- Не может гарантированно перехватывать Print Screen. Если браузер получил нажатие, открывается редактор; скриншот Windows нужно вставить Ctrl+V. Для полного перехвата нужна отдельная Windows-интеграция с учётом стандартных сочетаний.
- Браузер не может произвольно открыть папку Проводника. PNG скачивается через браузер.
- `Open-Meteo` работает только с интернетом и при явном вводе города. Стартовая погода помечена **DEMO**, пока нет подтверждённого ответа.
- Онлайн-поиск текстов осуществляется **только по кнопке** через LRCLIB (название/исполнитель отправляются этому сервису). Наличие синхронизированного текста не гарантировано; нет результатов — остаётся локальный LRC или демонстрация. Соблюдать условия использования и права на тексты.
- У истории редактора установлен лимит памяти 64 МиБ, поэтому на больших скриншотах число доступных шагов отмены может быть небольшим. Изображения с большей стороной свыше 4096 px уменьшаются с сохранением пропорций.
- Заметки и параметры сохраняются только в том браузере, где открыта страница. Снимки редактируются локально без загрузки на сервер.

### Проверка кода

При установленном Node.js:

```bash
node --test island-lab/tests/smoke.mjs
```

Проверяется синтаксис JavaScript, уникальность DOM ID, ссылки на ресурсы, разбор LRC, подбор синхронных текстов и геометрия обрезки. Тест не заменяет проверку в Windows и ручной UX-проход.

Основная ветка `main` намеренно не изменяется.
