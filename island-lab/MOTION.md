# Island Motion — единая система анимаций

Этот документ относится к веб-прототипу Island Lab и его **общему интерфейсу в Tauri/WebView2**. Не изменяет основной бинарник Snowy New Year.

## Визуальный принцип

Цель — ощущение плавной, физически связанной капсулы в духе iPhone Dynamic Island, **без попытки воспроизвести закрытые исходники Apple**. Анимации должны передавать причины действия: окно меняет форму, содержимое следует за ним, звук деформирует нижний край.

| Элемент | Реализация |
|---|---|
| Раскрытие/сворачивание | Согласованная анимация **ширины, высоты и скруглений**. Исходная и раскрытая панели перекрываются с разнесёнными по времени fade/translate, без скачка `display:none`. |
| Нативное окно | Перед раскрытием увеличивается прозрачный Windows WebView; **видимая капсула затем анимируется внутри**. При сворачивании сначала сжимается капсула, затем уменьшается область Windows. Команды изменения размера сериализованы. |
| Содержимое | Растущая капсула обрезает дочерние элементы по текущему скруглённому контуру. Волнистый край — соседний canvas и выступает **вниз**, вне маски капсулы. |
| Вкладки | Скользящий подсвеченный фон активной вкладки и переход содержимого (View Transitions API там, где доступен, CSS fallback иначе). |
| Текст песни | Три видимые строки. Предыдущий текст уходит вверх, новая строка появляется снизу; перемотка назад инвертирует направление. Поддержка локального LRC и LRCLIB не изменена. |
| Музыка/погода | При смене текста короткий fade+translate+умеренный blur. Время воспроизведения и seek обновляются **без анимации**, чтобы не создавать лаг. |
| Волна | 16 плавно интерполируемых частотных полос, пружинная огибающая, 60 FPS на активной музыке. При тишине форма затухает до прямой линии; при паузе остаётся короткий затухающий хвост. |
| Снег | Расчёт скорости по реальному времени между кадрами; теперь рендерится по частоте экрана вместо шага приблизительно 44 мс. |
| Элементы управления | Короткое уменьшение при нажатии; умеренный hover-отклик. |

## Профили

Три варианта в **Настройки → Характер анимаций**:

| Профиль | Геометрия | Содержимое | Текст песни |
|---|---:|---:|---:|
| **Плавный пружинный** (по умолчанию) | 560 мс | 400 мс | 520 мс |
| Быстрый отзывчивый | 390 мс | 270 мс | 340 мс |
| Спокойный мягкий | 700 мс | 520 мс | 590 мс |

Частотная огибающая использует аналитическую затухающую пружину, а не накопление покадровой ошибки. Результат одинаков при 30, 60 и 120 FPS (проверяется чистыми JS-тестами). Это математическая характеристика, **не гарантия частоты реального Windows-окна**.

Если включено **«Уменьшить анимации»** или система сообщает `prefers-reduced-motion: reduce`, декоративные переходы отключаются. Данные, кнопки, музыка и скриншоты продолжат работать.

## Нагрузка

- Никакой отдельный render loop для дизайна капсулы не нужен — переходы исполняются браузерным compositor.
- Волновой `requestAnimationFrame` работает лишь при музыке или затухании. Кадры UI-плеера обновляются с более редким интервалом, чем сама волна.
- Снегопад отключается при скрытой вкладке, нулевой интенсивности и пользовательском снижении анимаций.
- Для большего разрешения Canvas используется ограничение device pixel ratio; после изменения размеров волна синхронизируется с шириной капсулы через `ResizeObserver`.
- Когда нативная версия свернута, её прозрачная область сжимается вслед за капсулой — вне островка не должно оставаться постоянно большого невидимого окна.

## Как проверить

1. Открой `island-lab/index.html` в Chrome/Edge или запусти нативную сборку.
2. Проверь свернуть/развернуть несколько раз подряд. **Не должно быть рывков, появления карточек за границами капсулы и остаточного прозрачного прямоугольника**.
3. Переключай все пять вкладок, включая редактор с загруженным изображением. Индикатор вкладки должен плавно перемещаться, фокус оставаться на кнопках.
4. Запусти встроенную музыку. Нижняя волна должна плавно реагировать на звук и затухать при паузе. Проверь LRC и перемотку назад.
5. В **Настройки → Характер анимаций** последовательно выбери три профиля; включи «Уменьшить анимации».
6. Нажми **«Измерить плавность · 8 секунд»**. Во время замера открывай вкладки и запускай музыку. Замер показывает FPS, среднюю длительность кадра, P95 и число кадров дольше 33,4 мс. Результат остаётся локально и может быть включён в «Копировать отчёт».
7. На Windows повтори при масштабировании 100/125/150/200%, на 60/120/144 Гц, с несколькими мониторами и после смены системного режима энергосбережения.

### Критерии приёмки

Нужно подтвердить на ПК: отсутствие заметных скачков и мерцания, корректное выравнивание нижней волны, доступность кнопок во время морфа, корректную реакцию на быстрое переключение, отсутствие просадок FPS при простое. **Сборка и измерения на Windows пока не проводились в этой среде.** До этого нельзя утверждать, что реальный хост стабильно работает на 60/120 FPS.

### Архитектура

`motion.js` — примитивы `spring`, `smooth`, `updateLyrics`, `animateValue`, `onceTransition`; `styles.css` — общая система стилей и временных профилей; `app.js` — управляет состояниями без повторных render-циклов. Нативный Rust-хост предоставляет изменение размера окна, но не содержит дублирующей анимационной логики интерфейса.

Тесты: `node --test island-lab/tests/motion.test.mjs` либо общий `npm test` из `island-lab/native`.

## Улучшения перед проверкой на ПК

- Убран двойной вызов нативного расширения при клике на центральную кнопку.
- При ошибке изменения размера Windows-окна капсула не раскрывается за пределы доступной области.
- Во время сворачивания нижняя волна затухает **180 мс**, вместо мгновенного исчезновения. RAF прекращается при начале сворачивания.
- При переключении трека обложка мягко появляется; индикатор воспроизведения ненавязчиво меняет яркость.
- Убраны тяжёлые размытия целой панели, оставлены небольшие эффекты только на тексте.
- В тесте плавности **рывком** считается кадр длиннее 1,75 × типичной быстрой длительности кадра этого запуска. Это даёт более корректную оценку на 60/120/144 Гц, чем фиксированный порог 33,4 мс. Это оценка пейсинга, **не определение физической частоты монитора**.
- Для веб-версии добавлен локальный сервер `node island-lab/scripts/preview.mjs` с адресом `http://127.0.0.1:4173/`; только loopback и белый список файлов.

После запуска в Настройках выбери профиль анимаций, проверь быстрые двойные нажатия и запусти измерение FPS. В диагностике важнее не максимальное число FPS, а стабильность `P95` и число рывков.
